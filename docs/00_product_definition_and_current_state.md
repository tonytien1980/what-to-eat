# 00 產品定義與目前狀態

## 產品名稱

今天吃什麼：命運遠征

## 一句話定位

一個奇幻冒險風的命運拉霸機，幫大家在 1 到 2 分鐘內快速決定今天要吃哪裡。

## MVP 使用情境

- 同事站在一起快速決定午餐
- 朋友聚在一起決定晚餐、飲料或甜點
- 大家希望少討論、少猶豫，但過程有點好玩

## 核心原則

- 快速出結果
- 隨機優先
- 低操作成本
- 輕 RPG 氣氛，不做重 RPG 系統
- 不登入也能玩
- 同螢幕模式優先

## 第一版範圍

- 告示牌首頁
- 分類切換
- 開啟今日遠征
- 隨機命運卡
- 拉霸動畫
- 揭曉今日遠征目的地
- 地圖跳轉
- 一次性重抽

## 第一版非目標

- 帳號系統
- 即時多人房間
- 排行榜
- 成就徽章
- 角色養成
- 複雜投票或對戰規則
