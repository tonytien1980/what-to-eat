# 塔羅命運卡 Design Spec

## Goal

把命運卡從一般資訊卡升級成真正有奇幻塔羅牌感的揭示元件，讓使用者在按下開始後先看到卡背，再看到翻出的卡面。

## Product Change

- 命運卡揭示階段先顯示統一卡背
- 結果揭示後顯示帶有圖案、說明與色系的正面卡
- 不同命運卡要有不同重點色與氣質
- 卡片仍需維持在中央命運祭壇內，不可重新把背景蓋掉

## UX Direction

- 卡片比例偏向塔羅牌而不是一般橫向資訊卡
- 卡背要有命運之輪、符印與神祕感
- 正面要像同一套牌組，但每張卡仍有自己的屬性差異
- 動畫要短，不能拖慢抽餐流程

## Acceptance

- 按下 `開啟今日遠征` 後能先看到卡背
- 卡面揭示後能清楚辨識卡名、卡種與效果
- 卡片在手機尺寸仍保持可讀與可點擊
- 翻牌與抽選流程不影響既有重選規則
