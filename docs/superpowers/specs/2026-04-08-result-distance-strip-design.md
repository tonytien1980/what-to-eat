# 2026-04-08 Result Distance Strip Design

## Goal

在遠征結果翻牌完成後，於卡片下方、操作按鈕上方加入輕量距離資訊列，顯示玩家與目前遠征地的大約直線距離。

## Scope

- 不把距離資訊放進卡片正面
- 不把距離資訊塞進主按鈕文案
- 不把 geolocation 變成進站阻塞式流程
- 只在結果階段顯示距離資訊列
- 成功定位後要本地記住最近一次可用座標

## UX Rule

結果階段版面順序固定為：

1. 卡片
2. 距離資訊列
3. `出發去吃`
4. `再抽一次`

## Copy Rule

- 成功取得距離時：
  - `遠征地距離你約 450 公尺`
  - `遠征地距離你約 1.2 公里`
- 尚未取得定位時：
  - `啟用定位後可顯示遠征地距離`
- 定位進行中：
  - `正在確認你的位置...`
- 瀏覽器拒絕定位時：
  - `請先在瀏覽器允許定位，才能顯示遠征地距離`
- 暫時取不到定位時：
  - `暫時無法確認你的位置，請再試一次`

## Interaction Rule

- 不在 first load 自動要求定位
- 只在結果階段由玩家主動觸發定位
- 一旦本輪 session 已取得玩家座標，後續 reroll 可直接重算新目的地距離，不需重新詢問
- refresh 後若已有成功定位紀錄，應直接用本地記住的座標顯示距離
- 若目標店家缺少 `lat / lng`，距離資訊列直接不顯示

## Technical Rule

- 距離只計算直線距離，不計算步行 / 騎車 / 開車時間
- 直線距離使用正式 `lat / lng` 欄位
- geolocation 使用瀏覽器 `navigator.geolocation`
- 此功能不改變目前 location-aware 的 `city / district` 流程

## Non-goals

- 不做交通工具估時
- 不做自動定位首頁
- 不做 IP fallback
- 不做地圖路線 API
