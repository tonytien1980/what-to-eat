# 簡化祭壇與翻牌揭示 Design Spec

## Goal

把首頁從資訊過多的儀表板，重做成「背景為主、中央祭壇極簡、整張長牌翻面揭示結果」的奇幻抽牌體驗。

## Product Change

- 頂部資訊精簡，只保留主標、場景資訊與兩行天氣資訊
- `今天吃什麼` 與 `命運遠征` 固定兩行顯示，手機與桌機都不跑版
- 拿掉 `今天就吃這一家`、`中央氣象署 36 小時縣市預報`、`Google Sheet 即時資料`
- `午餐 / 晚餐 / 飲料 / 甜點` 改成奇幻徽章式切換
- `開啟今日遠征` 改成儀式感主按鈕
- 卡片本體改成長條直式撲克牌比例
- 翻牌後整張卡直接顯示目的地，不再顯示「命運卡」文案或卡牌效果文案
- `出發去吃` / `再抽一次` 移到卡片下方，讓卡片本體保持完整

## Card Back Rule

- 頁面載入時依權重抽出一張卡背
- `再抽一次` 時也會重新依同樣權重抽卡背
- 重新整理頁面自然會重新抽卡背
- 卡背素材來自 `images/backs/`
- 稀有度與權重如下：
  - `common`: 19.725% x4
  - `rare`: 8% x2
  - `epic`: 2% x2
  - `legendary`: 1% x1
  - `hidden`: 0.1% x1

## Rarity Glow Rule

- 所有卡背先有深色切邊與陰影，確保能從背景中站出來
- `common`: 普通白光
- `rare`: 高強度白光
- `epic`: 金光
- `legendary`: 紫光
- `hidden`: 藍光，接近 logo 色
- 翻牌過程的光暈可較強，翻完後要收斂，避免長時間過亮

## Reveal Flow

- 點擊 `開啟今日遠征` 後，先出現抽到的卡背
- 卡背先進入幾秒亂數儀式動畫
- 儀式完成後整張牌翻面
- 翻面正面以「撥雲見日」感的遮罩揭示餐廳名稱
- 結果揭曉後，卡片下方才出現操作按鈕

## Acceptance

- 首頁資訊密度顯著降低，背景仍清楚可見
- 主標固定兩行，不因螢幕寬度改成單行或三行
- 翻牌流程在桌機與手機上都完整可感知
- 卡背會依權重重新抽取，且 `再抽一次` 會連卡背一起重抽
- 既有 Google Sheet 資料來源、天氣場景、重抽與地圖跳轉仍正常
