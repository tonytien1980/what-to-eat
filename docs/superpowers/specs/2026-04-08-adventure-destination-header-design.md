# 2026-04-08 Adventure Destination Header Design

## Goal

重構首頁主標下方的資訊語意，避免同一個行政區同時代表「畫面場景」與「抽選範圍」造成混淆。

## Core Decision

首頁上半部只強調一個主要位置語意：

- `預計冒險地`

它代表：

- 目前這局要去哪個城市 / 行政區找餐廳
- 目前背景、景點、天氣與資料池都跟著哪個地區走

## Information Hierarchy

命運遠征大標下方固定改成：

1. `景點名稱 · 天氣狀態`
2. `預計冒險地：臺北市中山區　更改預計冒險地`
3. `預計冒險地 3 小時天氣預報`
4. `短暫陣雨 · 現在 20°`
5. `體感 21° · 今日 20°-25°`

## Rules

- 第一行不再顯示城市 / 行政區
- `預計冒險地` 的初始值仍吃系統猜到的建議值
- 使用者一旦手動更改 `預計冒險地`
  - 背景
  - 景點
  - 天氣狀態
  - `3 小時天氣預報`
  - 候選池
  - 可抽筆數
  都要一起同步

## Copy Changes

- `目前遠征地` -> `預計冒險地`
- `更改位置` -> `更改預計冒險地`
- `3 小時預報` -> `預計冒險地 3 小時天氣預報`
- `更改遠征地` -> `更改預計冒險地`
- `遠征地設定` -> `預計冒險地設定`

## Non-goals

- 不拆出第二個顯式「目前所在」欄位
- 不改距離資訊列位置
- 不改首頁 detect-first / local saved location 策略
