# 02 MVP Experience And Gameplay Spec

## 文件角色

本文件定義目前已啟用版本對玩家可見、可操作、可驗收的：

- UX 流程
- gameplay 規則
- 文案與世界觀轉譯
- 視覺與動效規範

## 產品氣質

- 奇幻冒險風
- 有儀式感
- 更像桌遊與派對工具
- 不像老派 RPG 官網
- 保持簡單、快速、直接

## 世界觀轉譯

- 餐廳 -> 據點 / 酒館 / 遠征地
- 抽籤 -> 命運指引
- 拉霸 -> 命運之輪
- 結果 -> 遠征結果
- 重抽 -> 逆天改命

## 目前可見選擇

目前前台只顯示 4 個遠征類型：

- 午餐
- 晚餐
- 飲料
- 甜點

這 4 類屬於單一決策場景中的輕量入口，不可演變成重度設定表單。

## 已啟用的 location-aware Phase 1 UX

這一段已經是目前上線行為；但目前只啟用 Phase 1，不包含 geolocation / IP-based city guess。

核心策略固定為：

`預先幫你猜，但永遠讓你輕鬆改。`

也就是：

- 不要每次打開都強迫選位置
- 永遠可看見目前使用中的城市 / 地區
- 永遠保留小而輕的人工修正入口
- 不用 full-page setup gate 打斷主流程

### First Visit

第一次進站時：

1. 若有本地記住的位置，直接使用
2. 若還沒有本地記錄，先顯示 `目前遠征地：臺北市中山區`
3. 不開啟阻塞式 setup gate
4. 使用者若想修正，再自行打開輕量 chooser

### Returning Visit

- 先讀取上次接受的位置
- first paint 直接使用
- 不重新打開 chooser
- 在目前位置行旁提供小型 `更改位置`

### Manual Correction

人工修正 UI 必須是輕量 panel 或 sheet，不是 full-page setup flow。

應包含：

- city dropdown
- district dropdown，並依 city 過濾
- `略過地區`
- `儲存並套用`

### Phase 2 Deferred Copy

以下文案保留到 geolocation / IP fallback 啟用時再使用：

- `要不要用你附近的地區幫你抽？`

## MVP 流程

### 1. 告示牌首頁

首頁必須包含：

- 固定兩行主標
- 台北市中山區天氣作為第一級資訊
- 主標下方場景 line
- 兩行壓縮後的天氣資訊
- 清楚可見的全場景背景
- 同天候下可於多張相容背景之間輪替
- 使用 `images/notice/` 的奇幻分類按鈕
- 首次載入預設不選任何類型
- 使用 `images/scrolls/` 的單一主 CTA
- CTA 文案需落在卷軸安全視窗內
- 開局前就先顯示一張當前卡背
- 一行目前遠征地狀態
- 低干擾的 `更改位置` 或 `補上地區`
- 不可把整頁變成阻塞式設定頁

### 2. 命運揭示與翻牌

揭示區必須包含：

- 長條直式撲克牌比例卡片
- 頁面載入或重抽時依權重抽一張卡背
- 翻牌後顯示對應稀有度的正面模板
- 與卡背稀有度一致的光暈
- 簡短卡背儀式動畫
- 一次翻牌轉場
- 翻牌後的撥雲見日式揭示
- 不拖慢回合節奏的 burst / settle pulse

### 3. 遠征結果

結果畫面必須包含：

- 目的地名稱作為卡面主內容
- 卡面上不顯示命運卡規則文字
- 卡片下方的 `出發去吃`
- 卡片下方的 `再抽一次`

## 核心玩法規則

### Hidden Destiny Rule

- 命運卡規則仍在背景控制過濾
- 不把規則文字直接露出在卡面 UI 上
- 重抽規則仍由 hidden destiny logic 控制

### Reroll Rule

- 每局保底可重選一次
- 若抽到 `宿命重骰`，額外再送一次
- `再抽一次` 會同時重抽卡背與目的地
- 次數用完後按鈕保留但禁用

### Card Back Rule

- 頁面打開就要先抽到一張卡背
- `再抽一次` 會依同樣權重再抽一張
- 稀有度與 face template 必須一致

目前權重：

- common：17.25% x4
- rare：10% x2
- epic：4% x2
- legendary：2% x1
- hidden：1% x1

## 動效規則

標準流程：

1. 先顯示卡背儀式動畫
2. 再整張牌翻面
3. 再以撥雲見日方式揭示餐廳名稱
4. 最後才顯示卡片下方操作按鈕

Reduced motion：

- 若使用者偏好 reduced motion，應直接簡化為快速揭曉
- 不可讓 reduced motion 使用者失去結果或操作能力

## 視覺規則

- 卡片必須是直式撲克牌比例，不是正方卡
- 卡背直接用圖檔，不用抽象符印佔位
- 正面使用對應稀有度的 face 模板
- 卡片有深色切邊與陰影，但不能被黑色大色塊包住
- 稀有度光暈要明顯區分
- 卡片後方用透明光場與 aura 分離，不用深色面板
- 場景背景必須清楚可見，面板只能局部遮罩
- 主標固定兩行，不因螢幕大小跑版
- 天氣與場景資訊壓成兩小行，避免 header 太滿

安全框與圖資參照：

- `docs/superpowers/specs/2026-04-06-artwork-safe-frames-and-flip-design.md`

## 內容與文案規則

- Traditional Chinese 是主要產品語言
- 可用奇幻包裝詞，但要維持好懂
- 結果畫面以快速接受與下一步行動為主
- 不把內容寫成平台式資訊堆砌
- 不在結果頁塞入過多 secondary CTA

資料來源產品化規則：

- Google Sheet / fallback source state 屬於正式 runtime 狀態
- 但它不是目前首頁的第一級資訊
- 若未來要露出，必須以低干擾方式呈現，不可把首頁拉回資訊過載狀態

Choice item 描述原則：

- 短
- 具體
- 有感
- 支援快速接受

較佳例子：

- 麵量穩、出餐快，適合中午不想想太多
- 甜度好調整，適合下午提神
- 氣氛穩、距離近，適合下班後輕鬆坐一下

## 成功標準

- first interaction 在 30 秒內開始
- one round 在 2 分鐘內完成
- 使用者能立刻理解結果
- 體驗比普通隨機抽選器更好玩
- 行動按鈕足夠清楚，能自然接到下一步
